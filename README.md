# ProjectGameGodotFPS
Este es un juego echo en godot y C++, la meta principal de este proyecto es entender la arquitectura y el uso de distintas técnicas para el el desarrollo de videojuegos, y el uso de C++ como lenguaje principal de programación.

Pretendo hacer una wiki para explicar la arquitectura y metodologia que se va usar para trabajar en el proyecto, mas que nada planeo hacer incrementos graduales, este conjunto de incrementos son parte de lo que seria un "sprint", porque mas tarde pretendo hacer otro paquete de incrementos para perfeccionar lo anterior o agregar mas caracteristicas para el juego

este proyecto aun no tiene nombre y aun no pretendo hacerlo, como dije anteriormente este proyecto es de testing

> ### Principales objetivos
>* Usar godot y c++ para la programación del videojuego
>* Priorizar la eficiencia, óptimizacion y rendimiento a la hora de programar
>* Mantener el enfoque de OPP para la escabilidad del juego
>* Divertirse
